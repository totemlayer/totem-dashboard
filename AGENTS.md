# Dashboard scope

This is the public Totem dashboard demo, licensed under MIT. Keep the visible demo disclosure and repository documentation accurate.

- Use sample fixtures and local simulations only.
- The owner authorized matching the current hosted dashboard UI. Only explicitly authorized presentation markup, artwork, and styles may be adapted from its source. Never copy private Git history, credentials, customer information, infrastructure configuration, service implementations, or runtime logic.
- Do not claim simulated messages, approvals, or Missions execute real agent work.
- Keep browser code independent of hosted Totem services and preserve `connect-src 'none'`.
- Preserve keyboard access, responsive layouts, and both color themes.
- Run `npm test` and `npm run build` after relevant changes.
