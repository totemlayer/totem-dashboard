# Contributing

Contributions to the dashboard interface, accessibility, responsive layout, demo interactions, and documentation are welcome.

1. Fork this repository and create a branch.
2. Run `npm start` with Node.js 22 or newer.
3. Make your change using fictional data only.
4. Run `npm test` and `npm run build`.
5. Check the affected screens with a keyboard, at a narrow viewport, and in both themes.
6. Open a pull request describing the behavior change and your checks.

Keep the visible demo disclosure accurate. Simulated actions should be named as simulations. Do not add real credentials, internal service URLs, customer information, analytics, or private platform code.

The project has no third-party dependencies. Discuss new dependencies and real service integrations in an issue before expanding that scope.

By submitting a contribution, you agree that it may be distributed under this repository's MIT license.
